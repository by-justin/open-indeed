自动驾驶数据闭环产品经理_XC

Company: Bosch Canada Location: Suzhou, Jiangsu, China URL: https://jobs.smartrecruiters.com/BoschGroup/744000150599199--xc

Job Description

岗位职责

  • 负责自动驾驶数据闭环产品的规划、设计与持续迭代，围绕 数据采集、数据回传、数据挖掘、数据筛选、数据标注、自动标注、数据质检、数据版本管理、训练数据交付 等核心环节，建设端到端的数据闭环能力。
  • 深入理解自动驾驶感知、预测、规控及端到端模型的数据需求，与算法、数据、研发、测试及业务团队协作，将模型需求转化为可落地的数据产品需求，包括：场景定义与数据需求拆解；Corner Case / Failure Case 挖掘；数据 Tag / Label / Ontology 体系设计；数据集构建及版本管理；数据覆盖度、质量及生产效率指标设计。
  • 负责数据闭环平台产品设计，包括但不限于：数据检索与数据资产管理；场景 Tagging 与数据 Mining；自动标注 / 预标注平台；人工标注生产流程；数据质检与验收；Dataset 管理与数据交付；数据生产任务管理及运营看板。
  • 建立数据生产和运营指标体系，从 Coverage、Quality、Efficiency、Cost、Delivery 等维度持续衡量数据闭环效果，例如：场景覆盖率；数据有效率；标注准确率及召回率；自动标注覆盖率；人均生产效率；单位数据生产成本；数据需求交付周期。
  • 与算法团队紧密合作，理解模型训练、评测以及 Failure Case，建立从： 模型问题 → 场景定义 → 数据检索 / 挖掘 → 数据生产 → 数据训练 → 模型评测 的闭环流程，持续提升数据对模型迭代的贡献效率。
  • 推动自动化、智能化数据生产能力建设，引入自动标注、VLM、多模态模型、数据挖掘算法、合成数据等能力，提高数据生产效率并降低人工成本。
  • 负责产品 Roadmap、PRD、流程设计及需求优先级管理，协调算法、平台、数据生产及项目团队推动产品落地，对产品交付结果负责。
  • 跟踪行业数据闭环技术及产品趋势，包括自动驾驶 Data Engine、Data Flywheel、Synthetic Data、Foundation Model、World Model 等方向，并结合实际业务推动能力演进。

Qualifications

任职要求

  • 本科及以上学历，计算机、人工智能、自动化、车辆工程、软件工程等相关专业优先。
  • 具备 3 年及以上产品、数据平台、自动驾驶或 AI 相关工作经验；有自动驾驶数据闭环、数据平台或 AI 数据产品经验优先。
  • 对自动驾驶数据链路有较深入理解，了解以下一个或多个领域：自动驾驶感知数据；Camera / LiDAR / Radar 等传感器数据；2D / 3D / BEV / OCC / Map 等数据形态；数据标注与自动标注；数据 Mining 与场景检索；模型训练与评测数据集。
  • 具备较强的数据分析能力，能够通过数据指标发现数据生产流程及模型数据需求中的问题。
  • 具备较强的抽象能力，能够将复杂算法和数据流程抽象为产品能力、平台模块及标准化流程。
  • 具备良好的跨团队协作和项目推动能力，能够协调算法、研发、数据生产、测试及业务团队推动复杂项目落地。
  • 具备基本技术理解能力，能够阅读技术方案，并使用 SQL / Python 等工具进行基础数据分析者优先。

加分项

  • 有自动驾驶量产项目经验；
  • 有数据闭环 / Data Engine / Data Flywheel 产品经验；
  • 有大规模自动驾驶数据生产或标注平台经验；
  • 熟悉数据湖、数据仓库、Dataset / Metadata / Data Lineage 等数据管理体系；
  • 熟悉自动标注、主动学习、数据挖掘、VLM / Foundation Model；
  • 有 3DGS、仿真、合成数据或 World Model 相关经验；
  • 有 AI 模型训练、模型评测或 MLOps 平台产品经验。
