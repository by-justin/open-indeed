¿En qué consiste el Young Talent Programme?

En Thales, creemos que las nuevas generaciones son las impulsoras del cambio y, por ello, hemos desarrollado un programa de  prácticas de un año a jornada completa que complementaremos con una formación en  Máster en Gestión Adaptativa e Innovación  impartida por la Fundación Universidad-Empresa (a distancia).

Durante tus prácticas como Software Engineering Intern:

  • Desarrollo de software ( Develop software )
  • Diseño ( Design )
  • Aplicaciones de mando y control ( Command and control applications )
  • Herramientas de soporte ( Support tools )
  • Pruebas unitarias y de integración ( Unit and integration tests )
  • Despliegue de entornos de prueba ( Deploy test environments )
  • Ejecución de procedimientos de prueba ( Execute test procedures )

¿Qué Buscamos?

En primer lugar y más importante…  ¡Jóvenes como tú!  Que tienen ganas de aprender, que cuentan con energía y entusiasmo, y que además se sienten motivad@s por los nuevos retos y el trabajo en equipo.

Además, nos gustaría que cumplieses con los siguientes requisitos:

  • Grado o Máster en titulaciones relacionadas con el área: ingeniería Informática / Ingeniería de Software, Ingeniería de Telecomunicaciones o afines.
  • Haber finalizado todas las asignaturas del grado/máster (a falta exclusivamente del TFG/TFM).
  • Alto nivel de inglés (al menos B2/C1).
  • Conocimientos avanzados en Excel y Paquete Office
  • Familiaridad con lenguajes como C#, Java, JavaScript y TypeScript
  • Capacidad analítica para la resolución de incidencias de software (mentalidad orientada a la resolución de problemas)
  • Comprensión básica de modelos cliente-servidor y comunicación
  • Que tengas iniciativa y ganas de aprender en un entorno internacional.
