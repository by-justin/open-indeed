Job Description

At ABB , we help industries run leaner and cleaner—and every person here makes that happen. You’ll be empowered to lead, supported to grow, and proud of the impact we create together. Join us and help run what runs the world.

This position reports to:

Sales Manager

__

一、职位概述

负责矿业客户的销售和业务拓展工作，建立并维护客户关系，深入了解客户需求、项目计划和采购流程，识别并推进销售机会，完成销售目标。

该岗位将与销售支持、产品、技术、商务、项目执行及服务团队紧密合作，推动项目报价、投标、商务谈判、合同签署和订单获取，为客户提供专业、及时和一致的支持。

二、主要职责

客户开发与销售管理

  • 开发并维护矿业客户关系，建立长期稳定的合作伙伴关系。
  • 深入了解客户业务发展规划、投资计划、项目需求和采购流程。
  • 建立并维护与客户管理层、技术团队、项目团队及采购团队的良好合作关系。
  • 制定并落实客户拜访、项目跟进和销售行动计划。

销售机会开发与项目推进

  • 识别和开发新的销售机会，推动销售目标实现。
  • 跟踪客户项目进展，及时了解客户需求、预算安排、招标计划和项目时间表。
  • 协调内部资源，为客户提供符合需求的产品、系统和服务方案。
  • 推动重点项目从需求识别、方案交流、报价投标到商务推进的全过程管理。

报价、投标与订单获取

  • 负责项目报价、投标、商务澄清和合同谈判工作。
  • 协调销售支持、产品、技术、商务和项目团队，确保投标和商务活动顺利推进。
  • 参与制定项目销售策略和赢单方案，提高项目成功率。
  • 推动合同签署及订单获取，并支持合同执行过程中的客户沟通与协调。

市场与竞争信息管理

  • 关注矿业行业发展趋势、客户投资动态和市场变化。
  • 收集客户需求、行业信息和竞争对手动态。
  • 分析市场机会并为销售计划和业务发展提供建议。
  • 维护客户和项目相关数据，支持销售预测和业务评审。

三、专业技能

  • 熟悉工业品销售流程及大型项目销售模式。
  • 具备矿业、冶金、电力、自动化或流程工业相关行业知识。
  • 熟悉客户开发、销售机会管理、报价投标和商务谈判流程。
  • 具备项目投标、合同管理、订单获取和商务协调能力。
  • 具备客户需求分析及解决方案销售能力。
  • 能够与销售支持、技术、服务、商务及项目团队高效协作。
  • 具备良好的英文读写及商务沟通能力。

四、能力要求

  • 优秀的客户关系管理能力。
  • 良好的商务谈判和影响力。
  • 较强的结果导向意识和销售驱动力。
  • 良好的计划、组织和执行能力。
  • 较强的沟通协调及跨团队合作能力。
  • 独立解决问题和推动事项落地的能力。
  • 能够适应出差并在动态环境下开展工作。
  • 具备持续学习和自我发展的意识。

五、教育背景与工作经验

教育背景

  • 本科及以上学历。
  • 电气工程、自动化、矿业工程、机械工程、工程管理、市场营销或相关专业优先。

工作经验

  • 3 年以上工业领域销售、客户管理或业务拓展经验。
  • 具有矿业、冶金、能源、电力、自动化或流程工业行业经验者优先。
  • 具有矿业客户、大型项目或工业设备销售经验者优先。
  • 具有项目报价、投标、商务谈判、合同签署或订单获取经验者优先。
  • 具备跨部门协同和复杂项目推进经验者优先。

六、加入 ABB，您将获得

  • 参与矿业行业重点客户和大型项目销售的机会。
  • 与 ABB 国内外销售、技术、产品、服务和项目执行团队合作的平台。
  • 在电气化、自动化和工业解决方案领域持续成长的机会。
  • 开放、协作和重视专业能力发展的工作环境。
