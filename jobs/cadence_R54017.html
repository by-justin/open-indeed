At Cadence, we hire and develop leaders and innovators who want to make an impact on the world of technology.

Job Title – Senior Boomi Integration Engineer

Position:  Senior Boomi Integration Engineer Location:  Onsite (Noida) Experience:  7+ years Grade: IT3

Job Summary

We are seeking a Senior Boomi Integration Engineer to design, build, and support  secure, scalable, and productionready enterprise integrations  using  Dell Boomi AtomSphere . This role is primarily focused on  Boomi development, APIled integrations, and production support , with strong  database development skills  and  Java  used as supporting capabilities to offload and centralize business logic where appropriate.

Core Responsibilities

  • Design, develop, deploy, and support  enterprise integrations using Dell Boomi AtomSphere
  • Build and manage  Boomi processes, APIs, connectors, listeners, and reusable components
  • Configure and manage  Atoms, Molecules, Atom Clouds , and environments across  Dev / Test / Prod
  • Implement  API management  including policies, throttling, rate limiting, and versioning
  • Develop integrations using  REST, SOAP, HTTP/S, FTP/SFTP, file-based, and event-driven patterns
  • Implement  robust error handling, alerting, retries, reprocessing, and exception frameworks
  • Support  Boomi Atom Queues  and asynchronous integration patterns
  • Work with  XML, JSON, CSV, EDI (X12 / EDIFACT)  and database-based integrations
  • Perform  Boomi platform governance , deployment management, and connector license administration
  • Provide  L2/L3 production support , monitoring integrations and meeting SLA/SLO requirements
  • Document integration flows, data mappings, dependencies, and operational runbooks

Java & Supporting Skills

  • Working knowledge of  Java 17 ,  Spring Boot , and  Microservices architecture
  • Build and consume  RESTful APIs  and  Webservices  using Java and webserver like Tomcat
  • Develop  custom Java or Groovy scripts  within Boomi for complex transformations
  • Experience writing core  Java   Batch  programs for bulk and scheduled processing

Database Development & Data Processing

  • Strong hands-on experience with  Oracle and PostgreSQL  databases
  • Write and optimize  complex SQL queries  to support integration and reporting
  • Design and develop  stored procedures, functions, and packages  to implement business logic at the database layer
  • Leverage  PL/SQL  (or equivalent procedural SQL) to handle Data Validation & Transformations, Aggregations and Calculations, High Volume data processing and batch operations
  • Tune queries, indexes, and execution plans for  performance and scalability
  • Collaborate with application and integration layers to  push logic down to the database  where appropriate
  • Troubleshoot  datarelated production issues  such as locking, performance degradation, and data inconsistencies

Security & Production Readiness (Must Have)

  • Strong fundamentals of  security protocols , including: SFTP, HTTPS, Encryption (PGP, AES) protocols
  • Hands-on experience in Key Managements, rotation, expiration handling
  • Experience managing  SSL/TLS certificates  like Installation, renewal, trust chains, keystores, and handshake errors
  • Wellversed in  common production issues , like Expired/Mismatched Certs, Invalid PGP Keys / Pass phrases, TLS/Cipher incompatibilities, Authentication & Authorization failures,  network, firewall, proxy and connectivity issues:
  • Ensure integrations comply with  enterprise security, compliance, and audit standards

Preferred / Huge Plus

  • Experience building and deploying Agentic AI modules using Boomi AI Agent Builder
  • Focus on  custom agent design and deployment ,  not  autogenerated integrations
  • Experience building  agent workflows outside of Boomi  and integrating them into Boomi is also a  strong plus

Required Experience

  • 7+ years of hands-on Dell Boomi experience  in enterprise environments
  • Strong background in  integration patterns, APIled connectivity, and production support
  • Proven experience supporting  missioncritical integrations  with strict SLAs
  • Strong  database development experience  (SQL, stored procedures, performance tuning)
  • Boomi Certifications  (Integration Professional, Solution Design Specialist)
  • Experience with  Salesforce, Coupa, SAP(ECC), S4/Hana, SharePoint, Office 365, and B2B/EDI integrations
