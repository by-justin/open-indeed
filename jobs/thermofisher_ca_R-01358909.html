Job Description

Sales Development Representative

Sales Development Representativeは、 お客様のニーズを見つけ、ビジネスのきっかけをつくる仕事 です。 大学や企業の研究者と話し、研究テーマや困っていること、今後必要になる技術を理解します。 その情報をもとに、電子顕微鏡を使った新しいソリューションを紹介し、営業活動をサポートします。 学会やイベントへの参加、市場・競合の調査、マーケティング活動にも携わります。 また、お客様の声を製品開発チームに届け、将来の製品づくりにもつなげます。 技術の知識を活かしながら、顧客・市場・ビジネスをつなぐポジションです。

Account Manager

Account Managerは、 お客様の課題を理解し、最適な製品を提案する営業職 です。 大学、研究機関、企業のお客様を担当し、研究や開発で何を実現したいのかを理解します。 その課題に合わせて、TEMやFIB-SEMなどの電子顕微鏡を提案します。 技術担当やサービス担当とチームを組み、製品紹介やデモ、導入までを進めます。 お客様と長期的な信頼関係を築くことも大切な役割です。 科学技術とお客様をビジネスの面からつなぐポジションです。

Application Scientist

Application Scientistは、 電子顕微鏡を使って、お客様の研究課題を技術的に解決する仕事 です。 お客様の研究テーマやサンプルを理解し、最適な観察・分析方法を考えます。 実際にTEMやFIB-SEMを操作し、サンプル評価やデモンストレーションを行います。 装置の使い方を教えたり、より良い分析方法を提案したりすることも重要な仕事です。 また、お客様の声を開発チームに伝え、新しい製品や技術の開発にも貢献します。 研究で身につけた専門知識を、お客様の課題解決に直接活かせるポジションです。

Field Application Engineer

Field Application Engineerは、 半導体メーカーの現場で、FIB-SEMを使った技術課題を解決する仕事 です。 装置の導入や操作トレーニング、技術サポートなどを担当します。 お客様が抱える解析上の問題を理解し、より良い分析方法や装置の使い方を提案します。 さらに、作業を効率化するための自動化や、新しい分析方法の開発にも取り組みます。 Salesや製品開発チームとも連携し、お客様の現場と製品開発をつなぎます。 最先端の半導体技術に近い場所で、技術力を活かして課題を解決するポジションです。

Field Service Engineer

Field Service Engineerは、 電子顕微鏡などの最先端装置を、お客様の現場で支える仕事 です。 装置の設置、定期メンテナンス、修理やトラブル対応などを担当します。 問題が起きたときには原因を調べ、装置を正常な状態に戻します。 機械、電気、電子、ソフトウェアなど、幅広い技術に触れながら専門性を高めていきます。 お客様の研究や製造を止めないために、装置の安定稼働を支える重要な役割です。 機械を触ることや、技術を使って問題を解決することが好きな人に合うポジションです。
