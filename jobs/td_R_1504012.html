Where You'll Work

You’ll be expected to work Primarily onsite at a TD location for meetings, team events and experiences. The hiring manager will provide more information about how this works for their team.

Job Requirements – What You Need to Succeed

  • Front-End (Client Side): Working experience in HTML, CSS, Javascript, React.
  • Back-End (Server side): Proficiency in Node.js, Java, Spring Boot, Spring framework, Restful webservices, asynchronous programming and authentication (JWT, OAuth)
  • Database Management : Competency in writing optimized queries, designing schemas, handling database migrations and understanding indexation.
  • API Systems: Ability to independently design and optimize RESTful APIs, focusing on payload efficiency and query latency.
  • Tools and Version Control: Experience with Git, package managers (npm) and API testing tools (Postman, SoapUI).
  • CI/CD & Cloud: Basic mastery of continuous integration workflows (Github Actions) and knowledge of Azure Cloud.
  • AI Tool Fluency: Ability to safely use AI assistants (like Github Copilot) to accelerate delivery while possessing the deep system knowledge required to debug, audit and correct AI generated code.
  • Testing Rigor: Writing reliable unit, integration and end-to-end tests using frameworks like Jest, Mocha, Junit etc.
