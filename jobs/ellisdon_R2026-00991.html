Overview

The Senior Infrastructure Analyst is responsible for designing, implementing, modernizing, and supporting enterprise infrastructure across hybrid environments, including on-premises data centers and Microsoft Azure. This role serves as a senior technical resource responsible for infrastructure architecture, server lifecycle management, cloud adoption, virtualization platforms, identity services, automation, and operational excellence.

The position plays a key role in infrastructure modernization initiatives, cloud transformation programs, platform engineering, and technology standardization efforts, ensuring solutions are scalable, secure, resilient, and aligned with organizational standards.

Key Responsibilities

Infrastructure Engineering, Platform Management & Modernization

  • Design, implement, administer, and optimize enterprise server infrastructure across Windows Server environments (2019–2025), ensuring reliability, scalability, performance, and security.
  • Lead server lifecycle management activities, including server provisioning, configuration, hardening, patching, operating system upgrades, migrations, decommissioning, and technology refresh initiatives.
  • Administer and support Active Directory, Group Policy, DNS, DHCP, PKI, Entra ID, and related Microsoft infrastructure services.
  • Manage and optimize virtualization platforms including VMware vSphere, ESXi, vCenter, and Hyper-V.
  • Support and administer enterprise application delivery platforms such as Citrix.
  • Develop and maintain infrastructure standards, server build specifications, operational procedures, and configuration baselines.
  • Serve as a senior escalation point for complex infrastructure issues and incidents.
  • Evaluate emerging technologies and provide recommendations for modernization, standardization, and continuous improvement initiatives.

Cloud Engineering, Infrastructure as Code & Hybrid Infrastructure

  • Design, implement, and support Microsoft Azure infrastructure services across hybrid cloud environments.
  • Lead and support migrations from on-premises infrastructure to Azure, including discovery, dependency assessment, architecture design, implementation, testing, cutover planning, rollback planning, and post-migration optimization.
  • Design and implement Azure infrastructure components including virtual machines, virtual networks, storage, identity services, monitoring solutions, availability configurations, and security controls.
  • Apply Infrastructure as Code (IaC) practices using technologies such as Terraform, Azure CLI, PowerShell, Bicep, ARM Templates, or similar automation and configuration-management tools.
  • Develop reusable, modular, and standardized Infrastructure as Code templates to support consistent and repeatable infrastructure deployments.
  • Maintain Infrastructure as Code configurations within source-control repositories and follow appropriate versioning, review, testing, and deployment practices.
  • Automate server provisioning, operating system configuration, infrastructure deployments, patching activities, compliance validation, and routine administration.
  • Identify opportunities to replace manual processes with secure, supportable, reusable, and auditable automation.
  • Develop and maintain Azure governance standards, including subscription management, resource organization, naming conventions, tagging standards, role-based access control, Azure Policy implementation, and lifecycle management.
  • Perform ongoing assessments of cloud environments to identify optimization opportunities, including rightsizing, utilization analysis, lifecycle management, and cost optimization initiatives.
  • Collaborate with application, network, database, and security teams to ensure successful deployment of cloud-native and hybrid workloads.

Solution Design & Infrastructure Architecture

  • Lead infrastructure solution design activities for enterprise projects, modernization programs, cloud adoption initiatives, and technology transformation efforts.
  • Produce and maintain infrastructure architecture diagrams, technical designs, implementation plans, migration strategies, and operational documentation.
  • Develop high-level and detailed architecture diagrams covering Azure, server infrastructure, Active Directory, Entra ID, virtualization, networking, storage, databases, security, high availability, and disaster recovery designs.
  • Translate business requirements, technical requirements, and security requirements into scalable and supportable infrastructure solutions.
  • Define Infrastructure as Code standards, reusable deployment modules, automation frameworks, and architecture patterns aligned with enterprise governance requirements.
  • Participate in architecture reviews, design assessments, technology evaluations, and technical governance processes.
  • Ensure solutions are designed with scalability, security, resiliency, supportability, maintainability, and cost effectiveness as key objectives.
  • Contribute to technology roadmaps, platform modernization strategies, cloud adoption plans, and lifecycle management decisions.

Operations, Monitoring, Patching & Continuous Improvement

  • Monitor infrastructure health, performance, capacity, availability, and configuration compliance across server, virtualization, cloud, identity, storage, and supporting platforms.
  • Lead patch management and update management activities across operating systems, virtualization platforms, Azure services, and other infrastructure technologies.
  • Establish structured patch-management processes covering testing, approvals, deployment, validation, rollback planning, exception management, and compliance reporting.
  • Work closely with Security teams to prioritize vulnerability remediation and implement infrastructure hardening standards.
  • Utilize PowerShell, Azure CLI, Terraform, Bicep, and similar tools to automate deployments, configuration management, monitoring, compliance reporting, and operational processes.
  • Review and maintain automation solutions to ensure reliability, security, maintainability, logging, and proper error handling.
  • Identify opportunities to standardize, simplify, and automate infrastructure operations.
  • Support audits, operational reviews, compliance initiatives, and infrastructure risk assessments.
  • Participate in change management, major incident response, root-cause analysis, and post-implementation reviews.

Infrastructure Resiliency & Recovery

  • Collaborate with Backup Administrators and Security teams to support enterprise backup, recovery, and resiliency capabilities.
  • Participate in disaster recovery testing and infrastructure recovery validation activities.
  • Ensure infrastructure solutions are designed with recoverability, high availability, and business continuity requirements in mind.
  • Support implementation of cyber recovery, immutable storage, and resilience-focused infrastructure capabilities where required.

Documentation & Governance

Create and maintain technical documentation including:

o Infrastructure architecture diagrams

o Server build standards

o Azure implementation designs

o Infrastructure standards and procedures

o Migration plans

o Operational runbooks

o Recovery and resiliency documentation

  • Develop and maintain documentation frameworks supporting systems administration, infrastructure architecture, security, and operational support functions.
  • Ensure documentation aligns with governance, compliance, operational excellence, and audit requirements.
  • Maintain accurate and audit-ready infrastructure records, technical standards, and configuration documentation.

Role Summary

The Senior Infrastructure Analyst is a senior technical contributor responsible for the architecture, engineering, modernization, and ongoing optimization of enterprise infrastructure services. The role provides advanced technical leadership across Windows Server, Active Directory, Entra ID, Microsoft Azure, VMware, Citrix, and hybrid platforms while driving infrastructure modernization, cloud adoption, migration initiatives, Infrastructure as Code practices, patch management, automation, and operational excellence. Through strong architectural expertise, hands-on technical leadership, and the use of modern automation technologies such as Terraform, Azure CLI, PowerShell, and Bicep, the position enables secure, scalable, resilient, and repeatable infrastructure delivery aligned with organizational standards and long-term technology strategy.
