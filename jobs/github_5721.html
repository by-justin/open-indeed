Overview

About GitHub

GitHub is the world's leading platform for agentic software development, powered by Copilot to build, scale, and deliver secure software. Over 180 million developers, including more than 90% of the Fortune 100 companies, use GitHub to collaborate, and more than 77,000 organizations have adopted GitHub Copilot.

Mission Control is the platform team behind GitHub's Copilot Coding Agent and the wider agentic developer experience. Internally, the service is known as the "Session Service" or "Task API": it is the system of record for every AI agent session and task created on GitHub.

Every time Copilot is assigned to an Issue, every copilot --remote or --cloud CLI session, every VS Code Chat, JetBrains Chat, or Copilot Chat conversation on github.com, its full lifecycle, from creation, through steering and events, to completion, is tracked, authorized, and served by the Go services this team owns.

This is a high-leverage platform role. You'll help scale a service that already sits in the critical path for every Copilot agent surface (CLI, VS Code, JetBrains, github.com chat, and the cloud coding agent itself), while also contributing to the next generation of agent capabilities: remote steering from web and mobile, host and enterprise managed policy enforcement, and the Agent Host Protocol (AHP) that lets any compliant client attach to a running agent environment.

We're looking for an engineer who can operate across the stack (API design, Go services, distributed data, and the security/authorization model that governs who can do what) and who enjoys foundational, cross-team problems. You should be comfortable owning significant components end to end, and driving designs that hold up under scale, security review, and a rapidly evolving product surface.

Responsibilities

Responsibilities

  • Design, build, and operate the Sessions and Tasks APIs (Go, Azure CosmosDB, Azure Blob Storage, Event Hubs) that back every Copilot agent surface: Copilot Coding Agent, Copilot CLI, VS Code Chat, JetBrains Chat, and Copilot Chat on github.com.

  • Own and evolve the agent registry and remote steering model, including the policies that decide who can create, edit, or remotely control a session (org/enterprise settings, MDM host managed settings, SSO organization requirements, and staff/internal bypass rules).

  • Drive spec first API design: propose changes to the OpenAPI description, regenerate strict server bindings, and coordinate breaking or additive schema changes across client and platform teams (copilot-agent-runtime, sweagentd, copilot-api, the github/github monolith, and github-ui).

  • Write architecture decision records and design proposals for new platform capabilities (for example: the Agent Host Protocol for user managed and sandboxed environments, token sealing and minting for secure relay, and unified steering across synchronous and asynchronous agents).

  • Ship safely at scale using staged, feature flag gated rollouts (observe-then-enforce patterns) across dotcom, GHES, and Proxima tenants.

  • Contribute technical leadership and mentorship through design review, pairing, and PR review, raising the bar on idiomatic Go, dependency injected and interface first design, and table driven testing.

  • Partner with adjacent teams on distributed systems concerns: CosmosDB data modeling and query performance, Kubernetes/Kustomize deployment configuration, Terraform provisioned Azure infrastructure, and service health/on call practices.

  • Contribute to cross-org design discussions (security/IAM, identity and step up authentication, enterprise policy) and help drive open questions to a shipped, well tested outcome.
