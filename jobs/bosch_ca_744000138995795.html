职位描述

关于团队

我们是自动驾驶研发体系下的 离线工具链与运营平台 团队，负责支撑数据标注、数据闭环、模型生产、车队运营、车端启动器等核心系统。平台涵盖 20+ 后端微服务、近 10 个 Web 应用、移动端及小程序，是连接「海量路测数据」与「算法 / 运营」的关键枢纽。

你需要能从浏览器一路打通到数据库与消息队列，独立负责一个业务方向从前端交互、后端服务到部署运维的全链路。

岗位职责

  • 端到端负责 ：独立主导一个或多个业务方向（如数据标注、数据闭环、模型生产 、运营管理），从需求、架构设计、前后端开发、联调到上线运维全流程闭环。
  • 架构设计与演进 ：设计高并发、大数据量场景下稳定可扩展的全栈架构，制定技术演进路线，统筹前端工程、后端微服务、数据建模与跨端协作。
  • 复杂场景攻坚 ：落地复杂可视化与交互（点云 / 图像标注、地图编辑、3D 渲染、浏览器端模型推理），同时设计与优化后端微服务、消息驱动与第三方平台对接。
  • 技术标准与质量 ：建立前后端工程规范、CI/CD、监控告警体系，推动代码质量、测试覆盖与交付效率提升。
  • 技术赋能 ：解决跨端（Web / Android / 小程序）疑难问题，对团队进行技术指导与人才培养。

职位要求

任职要求（硬性）

  • 本科及以上学历，计算机相关专业， 8 年以上 软件研发经验，具备大型系统全栈架构设计与落地经验。
  • 必须同时具备扎实的前端与后端能力 ，能独立交付完整业务系统，而非仅擅长其中一端。
  • 前端 ：精通 React 18 / TypeScript 5 ，深入理解 Redux Toolkit、Webpack 5 / Vite 工程化；熟悉 Vue 2 / 3 技术栈。
  • 后端 ：精通 Java / Kotlin 与 Spring Boot 生态 （Spring Data JPA、Spring Security / LDAP），熟悉 gRPC / Protobuf 微服务通信，掌握 MySQL 等关系型数据库设计与调优。
  • 中间件 & 运维 ：熟悉 Kafka / RocketMQ（阿里云 ONS）等消息队列、云对象存储（OSS / S3 / TOS）、分布式调度（SchedulerX），熟悉 Docker 容器化与微服务部署。
  • 具备扎实的数据结构、算法与系统设计功底，能独立攻克性能、并发、稳定性难题。

加分项

  • 可视化 / 图形学 ：OpenLayers、PIXI.js、Three.js、Canvas / WebGL 大规模渲染。
  • 浏览器端 AI 推理 ：TensorFlow.js、OpenCV.js、ONNX、Web Worker / WASM 多线程计算。
  • 跨端能力 ：Android（Kotlin + Coroutines + Room + OkHttp）或微信小程序开发经验。
  • 行业背景 ：自动驾驶 / 大数据 / 地图（GIS）/ 数据标注相关经验。
  • 大型微服务集群（10+ 服务）治理与可观测性建设经验。
  • 活跃的开源贡献或技术影响力。
