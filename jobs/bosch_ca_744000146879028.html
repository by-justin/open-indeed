数据平台 Java 开发工程师 _XC

Company: Bosch Canada Location: Suzhou, Jiangsu, China URL: https://jobs.smartrecruiters.com/BoschGroup/744000146879028--java-xc

Job Description

岗位描述 / Job Description

负责数据平台后端服务及相关工具的设计、开发与维护，基于 Java 技术栈构建稳定、可扩展、易维护的平台能力，并在 Linux 和 Docker 环境中完成开发、部署与问题排查。该岗位将与业务、测试及基础设施团队协作，持续提升数据处理效率和平台用户体验。

Design, develop, and maintain backend services and related tools for the data platform. Build reliable, scalable, and maintainable platform capabilities using the Java technology stack, and develop, deploy, and troubleshoot services in Linux and Docker environments. This role collaborates with business, testing, and infrastructure teams to continuously improve data processing efficiency and platform user experience.

岗位职责 / Responsibilities

  • 使用 Java 开发和维护数据平台后端服务、数据接口及通用功能模块。 Develop and maintain data platform backend services, data APIs, and reusable functional modules in Java.
  • 参与数据采集、处理、存储、检索及任务管理等平台功能的设计与实现。 Contribute to the design and implementation of platform capabilities for data ingestion, processing, storage, retrieval, and job management.
  • 参与数据库表结构、接口和服务模块设计，持续改进系统性能、稳定性和可维护性。 Contribute to database schema, API, and service module design, and continuously improve system performance, reliability, and maintainability.
  • 在 Linux 和 Docker 环境中完成应用开发、构建、部署、运行维护及故障排查。 Develop, build, deploy, operate, and troubleshoot applications in Linux and Docker environments.
  • 编写单元测试、集成测试和技术文档，参与代码评审及 CI/CD 流程建设，保障软件交付质量。 Write unit and integration tests and technical documentation; participate in code reviews and CI/CD development to ensure software delivery quality.
  • 与产品、测试、运维及平台用户协作，理解实际需求，推动功能按计划交付并持续优化。 Collaborate with product, testing, operations, and platform users to understand practical needs, deliver features as planned, and drive continuous improvement.

Qualifications

岗位要求 / Requirements

  • 计算机科学、软件工程或相关专业本科及以上学历，或具备同等水平的项目实践经验。 Bachelor's degree or above in Computer Science, Software Engineering, or a related field, or equivalent practical project experience.
  • 具备扎实的 Java 开发经验，熟悉面向对象设计、常用 Java 开发框架及后端服务开发。 Solid Java development experience, with knowledge of object-oriented design, common Java frameworks, and backend service development.
  • 具有数据平台、工具平台、云平台或企业级后台系统的开发经验，能够独立完成软件模块的设计、开发、测试和交付。 Development experience with data platforms, tooling platforms, cloud platforms, or enterprise backend systems; able to independently design, develop, test, and deliver software modules.
  • 熟悉关系型数据库、SQL 及 RESTful API，了解微服务和分布式系统的基本设计原则。 Familiar with relational databases, SQL, and RESTful APIs, with an understanding of fundamental microservice and distributed-system design principles.
  • 熟悉 Linux 开发环境和常用命令，能够使用 Docker 构建、运行和调试应用。 Comfortable with Linux development environments and common commands; able to use Docker to build, run, and debug applications.
  • 熟悉 Git 协作流程，具备良好的代码质量、测试和技术文档意识。 Familiar with Git-based collaboration, with strong awareness of code quality, testing, and technical documentation.
  • 具备责任心和团队协作意识，能够主动理解需求并解决实际问题。 Demonstrates ownership and teamwork, with the ability to proactively understand requirements and solve practical problems.

加分项 / Nice to Have

  • 具有自动驾驶、智能驾驶或 ADAS 相关工作或项目经验，了解自动驾驶研发流程及数据应用场景。 Work or project experience in autonomous driving, intelligent driving, or ADAS, with an understanding of AD development workflows and data use cases.
  • 具备良好的沟通表达和跨团队协作能力，能够清晰说明技术方案、进展和风险。 Strong communication and cross-functional collaboration skills, with the ability to clearly explain technical solutions, progress, and risks.
  • 具备良好的英语口头和书面能力，能够在国际化团队中开展技术沟通与协作。 Good spoken and written English, with the ability to communicate and collaborate in an international engineering team.
  • 熟悉 Kubernetes、消息队列、任务调度、监控告警或主流云平台。 Familiarity with Kubernetes, message queues, job orchestration, monitoring and alerting, or major cloud platforms.
  • 具有大规模数据处理、性能优化或生产环境故障排查经验。 Experience with large-scale data processing, performance optimization, or production troubleshooting.

我们提供 / What We Offer

  • 参与核心数据平台建设，将实际业务需求沉淀为稳定、可复用的平台能力。 Contribute to core data platform development and turn practical business needs into stable, reusable platform capabilities.
  • 与业务、测试及基础设施等多个团队深度协作，持续拓展平台开发与数据工程能力。 Collaborate closely with business, testing, and infrastructure teams while growing platform development and data engineering expertise.
