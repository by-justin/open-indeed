雷达工具链与调试工程师_XC

Company: Bosch Canada Location: Suzhou, Jiangsu, China URL: https://jobs.smartrecruiters.com/BoschGroup/744000149818582--xc

Job Description

岗位定位：负责雷达工具链的设计、验证、开发与集成，重点围绕调试工具应用、多协议数据同步工具开发及可视化调试平台建设，为雷达/转台等系统研发提供工具与数据支撑。本岗位需同时具备底层协议理解能力与上层工具开发能力，是连接硬件调试、协议解析与数据可视化的关键角色。

一、岗位职责

  • 与global团队一起调试雷达，在本地进行验证以及环境搭建。
  • 调试与工具链建设：熟练使用 Lauterbach Trace32 等调试工具，配合软硬件团队完成目标板（MCU/SoC）的在线调试、Trace 跟踪、性能分析与问题定位。
  • 同步工具开发：根据转台与雷达的通信协议（控制指令、状态回传、时序同步等），设计并开发二者之间的数据同步/联调工具，实现角度-回波数据的时间对齐、协议转换与联合录波回放，支撑雷达外场标校与转台联调测试。
  • 多协议接口开发与调试：承担以太网（TCP/UDP/Socket）、CAN、MIPI 等总线/接口协议的解析、抓包与调试工作，完成上位机与嵌入式设备间的数据链路打通与稳定性验证。
  • 可视化工具开发：基于 Qt（C++）在 Linux 平台开发调试与数据分析的上位机工具，实现协议数据实时显示、波形绘制、报文解码等功能，持续迭代团队内部工具链 zhaopin.com+1 。
  • 抓包与数据分析：使用 Wireshark 等网络/总线分析工具对以太网、CAN 报文进行捕获、解码与问题回溯，输出分析报告并推动问题闭环。
  • 文档与流程输出：编写工具使用手册、接口协议文档、测试用例与调试指南，推动工具链在团队内的标准化复用。
  • 以及其他团队所需任务

Qualifications

二、任职要求

基本条件

  • 本科及以上学历，计算机、电子信息、通信工程、自动化等相关专业；
  • 3 年以上嵌入式/上位机工具开发相关经验，有雷达、光电、汽车电子或工控领域工具链建设经验者优先。

硬性技能

  • 调试工具：熟练掌握 Lauterbach Trace32（PowerDebug/PowerTrace），具备单步调试、断点、变量观测、Trace 分析及 CMM 脚本编写能力，能独立定位实车/实装问题 liepin.com+1 。
  • 协议开发：熟悉以太网、CAN、MIPI 等通信协议的底层原理与报文格式，具备自定义协议解析、协议转换与同步机制设计的实际项目经验；理解转台-雷达类系统在时序对齐、数据同步上的工程挑战者优先。
  • 可视化工具开发：精通 C/C++ 与 Qt 框架（信号槽机制、多线程、自定义控件、QCustomPlot/QWT 等图表库），能独立完成调试类上位机工具的架构设计与功能实现 elecfans.com+1 。
  • Linux 能力：熟悉 Linux 开发环境（Shell、交叉编译、Socket 编程、多进程/多线程），有嵌入式 Linux 平台上的工具部署与适配经验 liepin.com+1 。
  • 抓包分析：熟练使用 Wireshark 进行以太网报文捕获、协议解码与问题定位，熟悉 CANoe/CANalyzer 等总线分析工具者优先。

软性素质

  • 逻辑清晰，具备较强的跨团队沟通能力，能与硬件、算法、测试工程师高效协作；
  • 对工具化、自动化有热情，能主动将重复性调试工作沉淀为通用工具；
  • 具备良好的英文技术文档阅读能力。

三、加分项

  • 有转台和雷达工具开发经验；
  • 熟悉 CANopen、SOME/IP、AVB/TSN 或车载以太网等高级协议；
  • 英文可以作为工作语言加分。
