Job Description

Your Role

Member of Technical Staff - Cloud Operations

ROLES AND RESPONSIBILITIES

As a Member of Technical Staff - Cloud Operations, you will help design, secure, automate, and operate scalable cloud environments that support Wind River engineering and business priorities. You will work across cloud architecture, DevSecOps, infrastructure automation, security-by-design, and operational excellence in a globally distributed environment.

Core Competencies & Demonstrated Success

  • Architect, design, deploy, and operate secure cloud environments across AWS, Azure, and/or GCP.
  • Automate cloud infrastructure and operational processes using Infrastructure as Code tools such as Terraform, OpenTofu, Terragrunt, AWS CDK, or CloudFormation.
  • Build and enhance CI/CD pipelines using platforms such as GitLab, Jenkins, GitHub Actions, or Azure DevOps.
  • Integrate security earlier in the software development lifecycle through SAST, DAST, SCA, secrets scanning, and IaC security controls.
  • Develop automation and tooling using Python, Bash, PowerShell, Go, or comparable scripting languages.
  • Apply cloud security fundamentals, including IAM, credential management, encryption, networking, subnetting, routing, and VPNs.
  • Support Linux and Windows environments, with a strong preference for hands-on Linux administration.
  • Lead and collaborate on cloud and security initiatives across geographically distributed engineering, security, and platform teams.
  • Proactively identify opportunities to improve reliability, security, efficiency, and cloud operating practices.
  • Apply AI-enabled tools or practices to cloud operations, automation, or security where relevant.

YOUR BACKGROUND

  • Bachelor’s degree in Computer Science, Engineering, Information Technology, or a related field, or equivalent practical experience.
  • 8+ years of progressive IT, cloud engineering, infrastructure, DevOps, or related experience.
  • Deep understanding of cloud architecture principles and core AWS, Azure, and/or GCP use cases.
  • Proven hands-on experience designing and deploying cloud environments, Infrastructure as Code, CI/CD automation, and DevSecOps practices.
  • Solid systems administration, networking, and cloud security knowledge.
  • Strong analytical, communication, problem-solving, and stakeholder collaboration skills.
  • Ability to work independently, lead technical initiatives, and deliver solutions across cross-functional and globally distributed teams.
  • Preferably AWS Solutions Architect or Microsoft Azure Solutions Architect certification is preferred.
  • Exposure to artificial intelligence technologies or AI-enabled cloud operations is a plus.

About Open Indeed

Open Indeed is a free, public job board created to help Canadian undergraduate students and new graduates discover verified tech internships, co-ops, and early-career opportunities.

Postings are indexed directly from official employer career portals via an autonomous scraping pipeline and updated on a recurring schedule—keeping listings timely, accurate, and completely free of spam or recruiter reposts.

The complete data collection and indexing pipeline is currently undergoing active reliability testing and will be fully open-sourced once thoroughly verified.
