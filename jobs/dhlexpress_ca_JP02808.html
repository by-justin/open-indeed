Job Description

About us

部門：インフラストラクチャ部門

ポジション名：Client Service System Senior Analyst（IT Infrastructure / End User & Server Support / M365 Operations）

【ポジション概要】

ビジネスの成長を支えるITインフラの設計・運用・改善を担うポジションです。

DHLでは 2030年に向けて事業規模を倍増する成長戦略 を掲げており、ITはその実現を支える重要なドライバーの一つです。

本ポジションでは、新規案件の立ち上げから既存拠点の品質向上までを担い、 現場ユーザーから経営層（SMT）までの幅広いステークホルダーと連携しながら、 “One Team”として課題解決と価値創出を推進していきます。

単なるIT運用ではなく、 ビジネスをITで加速させる中核メンバー として、熱意を持って取り組んでいただける方を求めています。

Responsibilities

【主な業務内容】

■ ITインフラ設計・運用（サーバー／エンドポイント環境）

  • PC・プリンタ・RF端末・モバイルなどのエンドポイントの設計、キッティング、展開

  • エンドポイント管理および標準化（Windows環境）

  • サーバー環境の運用・構成管理・改善

  • 倉庫・オフィス拠点のエンドポイントに関わるIT環境立ち上げ

■ ディレクトリ・M365運用

  • Microsoft 365（Office製品 / Teams / OneDrive）の運用・改善

  • Active Directoryによるアカウント・アクセス権管理、ユーザーサポート

  • DHL標準ソリューションを利用しての、ユーザー体験向上施策の企画・実行

  • Microsoft Copilotなど新技術の導入・活用

■ ITサポート・運用改善

  • ITインフラ（エンドポイント）に関わる、インシデント／リクエスト対応

  • 障害切り分けおよび国内サポートベンダー、APACサポートチーム連携

  • エンドポイントデバイスライフサイクル管理（調達〜廃棄）

  • Runbook整備・プロセス改善

■ 新規ビジネス・プロジェクト対応

  • ITインフラ（エンドポイント）構成の検討およびコスト見積

  • 倉庫立ち上げ・刷新プロジェクトへの参画

  • 小〜中規模プロジェクトの推進（例：特定の部門へのモバイル端末展開プロジェクト（小）、新規サイト立ち上げインフラリード（中））

  • ネットワーク・アプリチームとの連携

■ ステークホルダー連携

  • 現場ユーザーの課題ヒアリングと改善提案（エンドポイント）

  • オペレーションマネージャー・ビジネス部門との要件調整

  • APAC ITやグローバルITとの連携をおこない、協力して価値を創造する

  • 外部ベンダー（Desktop supportベンダー）との協働およびパフォーマンス管理（One Teamとして価値創出を推進）

■ セキュリティ・ガバナンス

  • DHLグループのグローバルセキュリティポリシーに基づく環境設計・運用

  • データ保護・アクセス管理

  • ITコストの最適化など

Requirements

【応募要件】

必須

  • ITインフラまたはITサポート経験（5年以上）

  • Windows PCやプリンタ、モバイル、スキャナなどのエンドポイント管理経験

  • サーバー管理経験（基本的な理解または運用経験）

  • M365/Active Directory管理経験

  • ITに関する全般的なトラブルシューティング経験（PC/プリンタ/RF端末などのエンドポイントのみならず、基本的なネットワークやサーバーの知識経験も含む）

  • ステークホルダー調整（現場ユーザーおよびマネージャー）経験

  • 日本語：ビジネス（N2以上）

  • 英語：ビジネスレベル（コールで海外のステークホルダーとコミュニケーションが取れる）

歓迎
