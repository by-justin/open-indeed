Description

Job Description

The Oracle Cloud Infrastructure team is building and operating a broad set of highly available, massively scalable cloud services in a distributed, multi-tenant cloud environment. OCI gives engineers the opportunity to work on systems that directly power business-critical workloads for customers across commercial, government, sovereign, and regulated cloud regions.

We are looking for hands-on engineers who are excited to solve difficult distributed systems problems, build resilient production services, and improve the internal platforms that enable OCI teams to build, validate, secure, and release software safely at cloud scale. At OCI, engineers have meaningful technical and business impact by designing, implementing, operating, and improving foundational systems used across Oracle Cloud.

Team Description

The OCI BUILD team owns critical internal build infrastructure and services used by OCI engineering teams to produce, validate, secure, and publish software artifacts. BUILD systems sit on the path between source code and production deployment, making them essential to OCI’s software supply chain, release velocity, security posture, and operational reliability.

The team works on distributed build services, build orchestration, CI/CD integrations, artifact publishing workflows, dependency management, build isolation, security controls, operational automation, compliance support, and customer-facing developer experience for internal OCI service teams. BUILD engineers partner closely with deployment, artifact, pipeline, security, compliance, region build, and service-owner teams to improve how software is built and released across OCI.

Who Are We Looking For?

We are looking for a senior software engineer with strong distributed systems fundamentals and production service experience. You should be comfortable owning the design and development of major service features, driving implementation through production launch, and operating services that must be reliable, secure, and scalable across a large internal customer base.

The ideal candidate is a strong  engineer and a practical systems thinker. You can work independently on complex projects, dive deep into service internals, reason about distributed failure modes, and collaborate across teams to deliver production-quality solutions. You value simple designs, measurable impact, operational excellence, and secure-by-default engineering.

You should be comfortable working on systems where source code, build inputs, third-party dependencies, secrets, logs, artifacts, policies, and release metadata must be handled with strong security, compliance, availability, and auditability requirements.

What Are the Biggest Challenges for the Team?

BUILD systems are foundational to OCI engineering productivity and software supply-chain security. As OCI continues to grow across commercial, government, sovereign, and regulated environments, BUILD must scale to support more services, more regions, stronger security requirements, faster release cycles, and greater automation.

Key challenges include improving build scalability and reliability, reducing build latency and operational toil, strengthening artifact and dependency provenance, hardening build isolation and authorization boundaries, modernizing CI/CD integrations, improving observability and self-service debugging, and using AI-driven automation to accelerate triage, build failure analysis, test generation, and developer productivity.

Responsibilities

Responsibilities

As an Senior Software Developer on the OCI BUILD team, you will:

  • Design, implement, test, deploy, and operate major features for OCI build services and supporting infrastructure.
  • Build and improve distributed services, APIs, orchestration workflows, build execution systems, and CI/CD integration points.
  • Own production-quality improvements across build reliability, scalability, performance, security, and developer experience.
  • Work on systems that manage build inputs, artifacts, third-party dependencies, build logs, credentials, policies, and publishing workflows.
  • Improve automation around build execution, artifact generation, dependency ingestion, validation, and release readiness.
  • Participate in design reviews, code reviews, operational reviews, and production readiness assessments.
  • Own production issues through root-cause analysis, remediation, follow-up fixes, and long-term reliability improvements.
  • Build observability, dashboards, alarms, runbooks, and debugging tools that help internal customers self-serve common build and release issues.
  • Collaborate with partner teams across OCI, including Pipelines, Artifact, DevOps, Security, Compliance, Region Build, ODO, Exec, Test, and service-owner teams.
  • Apply security and compliance principles to service design, including authentication, authorization, secret handling, auditability, artifact integrity, dependency provenance, and secure service-to-service communication.
  • Contribute to engineering quality through documentation, automated tests, operational tooling, and repeatable launch processes.

Required Qualifications

  • 4+ years of software development experience building and operating distributed services.
  • Strong development experience in Java, C++, C#, Go, Python, or similar programming languages.
  • Strong understanding of data structures, algorithms, operating systems, networking, and distributed systems fundamentals.
  • Experience designing and launching production features, including design documentation, implementation, testing, rollout, and operational follow-through.
  • Experience operating production services, including monitoring, alarms, incident response, debugging, and root-cause analysis.
  • Good understanding of databases, persistence layers, service state management, and distributed failure handling.
  • Experience working independently on complex technical tasks while collaborating effectively with partner teams.
  • Strong written and verbal communication skills, including clear design documents, operational updates, and technical tradeoff analysis.

Preferred Qualifications

  • Hands-on experience developing services on a public cloud platform such as Oracle Cloud, AWS, Azure, or GCP.
  • Experience with build systems, CI/CD platforms, release automation, artifact publishing, dependency management, or developer productivity infrastructure.
  • Experience building or integrating with systems such as Maven, Gradle, Artifactory-style repositories, container registries, pipeline engines, or internal deployment platforms.
  • Experience developing or operating Kubernetes-based applications, job execution platforms, or containerized service infrastructure.
  • Experience with supply-chain security concepts such as artifact signing, provenance, dependency control, vulnerability management, SBOMs, and secure publishing workflows.
  • Understanding of cloud security concepts such as IAM, resource principals, mTLS, secret management, audit logging, authorization boundaries, and secure service-to-service communication.
  • Experience applying threat modeling, risk analysis, or security review practices to distributed systems.
  • Familiarity with compliance-sensitive environments, government cloud requirements, or regulated cloud operations.
  • Experience with observability systems, logging pipelines, metrics, dashboards, alerting, and production debugging.
  • Interest in applying AI-assisted automation to build failure diagnosis, CI/CD optimization, security analysis, operational triage, documentation, or developer productivity.
