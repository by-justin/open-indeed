Job Responsibilities:

Mission

  • The architecture engineer is responsible for the architecture design and work product development. 架构工程师负责完成软件/系统架构设计以及相关工作产物的开发;
  • The ideal candidate should be a technical decision maker in design solution selection in both hardware and software aspects. 理想的候选人应该是硬件和软件设计方案选择的技术决策者;
  • A person in this role should also be a talented communicator with stakeholders either inner or outside development team. 担任此角色的人还应善于与开发团队内部及外部的利益相关者进行沟通;
  • The ideal candidate should be experienced in using UML and FMEA tool. 理想候选人应具有使用 UML 和 FMEA 工具的经验。

Position Responsibility

  • Complete system architecture development using Enterprise Architecture and IQR. 使用 EA 和 IQRM 完成系统架构开发;
  • Complete the bi-directional traceability between system requirement and system architecture design. 完成系统需求和系统架构设计之间的双向链接;
  • Leading the FMEA activity in development team. 领导开发团队内部的 FMEA 活动;
  • Complete the HSIS documentation, collaborate with hardware team. 与硬件团队合作完成 HSIS 文档;
  • Hardware component selection according to the system requirement and the feature and performance
  • specification of hardwar. 根据系统需求和硬件的功能，性能规格书，完成硬件选型;
  • System capability analysis, e.g. CPU load calculation. bus load calculation, Ram and persistent memory
  • consumption calculation系统能力分析，例如 CPU 负载计算、总线负载计算、RAM 和非易失存储的消耗计算;
  • Complete functional safety development, cyber security development collaborate with FUSA and Cyber
  • Security team. 与功能安全，网络安全团队合作完成功能安全，网络安全开发。

Position requirements

Required Qualifications

  • Master’s degree or above in Electrical/Computer Engineering. 电气/计算机硕士或以上学历;
  • Work experience in embedding system or ADAS algorithm in automotive electronics industry. 有汽车电子行业嵌入式系统或 ADAS 算法工作经验；
  • At least 5 years’ experience in system requirement or system architecture development in automotive electronics industry.  至少 5 年汽车电子行业系统需求或系统架构开发经验。

Soft Skills Requirements

  • The ability to solve problems, when facing complex technical challenges, can quickly identify the root cause and propose systematic solutions. 解决问题的能力，面对复杂的技术难题，能够快速定位根本原因，并提出系统性的解决方案;
  • Document writing skills, capable of creating clear, rigorous and unambiguous technical documents. 文档撰写能力，能够编写清晰、严谨、无歧义的技术文档;
  • Great problem-solving ability and self-learning skills. 出色的解决问题能力和自学能力;
  • Great oral and written communication in Chinese and English. 出色的中英文口头和书面沟通能力。
