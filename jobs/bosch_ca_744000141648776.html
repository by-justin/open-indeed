Job Description

岗位核心价值:

统筹研发整体预算与项目成本，把控研发全流程成本风险，通过专业化成本规划与管控，实现研发资源高效利用，助力务稳健、高效开展。

岗位职责:

  1. 支持整体研发成本管控与规划工作，统筹研发全流程成本管理，搭建规范化的研发成本管控体系。

  2. 支持研发年度、季度、月度整体预算编制、拆解、复盘与调整工作，精准把控研发预算执行进度，分析预算偏差原因并输出优化方案。

  3. 支持研发项目全生命周期成本控制，跟踪各研发项目成本投入、支出情况，实时监控成本风险，杜绝超预算、不合理支出。

  4. 专项负责数据分析及规划统筹工作，输出各类研发成本管控报表、分析报告。

  5. 对接研发、项目、财务等相关部门，同步成本数据、核对成本信息，协调解决研发成本管控过程中的各类问题。

  6. 持续优化研发成本管控流程与标准，沉淀成本管控经验，助力公司降本增效。

Qualifications

  1. 本科及以上学历，财务、会计、成本管控等相关专业优先，有制造业、科技行业研发成本管控经验者优先。

  2. 3-5年研发/工程成本控制、预算管理相关工作经验，熟悉研发成本核算、预算编制、项目成本管控流程。

  3. 熟练使用Excel、PPT及各类办公系统，数据敏感度高，擅长数据整理、分析及问题复盘。

  4. 具备良好的跨部门沟通能力、执行力和责任心，工作细致严谨，具备较强的风险把控意识和逻辑思维能力。
